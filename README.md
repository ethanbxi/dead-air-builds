# Dead Air: test builds

Windows builds of **Dead Air**, a 4-player co-op horror driving game, for playtesting.

## Playing

1. Open the [latest release](../../releases/latest) and download **DeadAir-windows.zip**.
2. Unzip it somewhere you can write to, such as Documents or Desktop. Not Program Files: the game updates itself in place.
3. Run **DeadAir.exe**. Windows SmartScreen may warn that the app isn't recognised. Choose *More info*, then *Run anyway*.

After that the game checks for a newer build each time it starts and installs it on its own. Updates are about 1 MB.

The game runs borderless at your monitor's resolution. **F11** switches to a window, **Esc** frees the mouse, and the
**Leave** button returns to the menu, where **Quit** is.

## Multiplayer

The host picks **Host a co-op session**. Everyone else picks **Join** and types the host's address, port 24690.
When Windows Firewall asks, allow Dead Air.
